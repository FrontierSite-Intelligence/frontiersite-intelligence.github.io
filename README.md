# FrontierSite Intelligence — Website

This repository contains a static landing page for FrontierSite Intelligence.

## Publish with GitHub Pages

1. Create a **public** repository owned by your organization with the exact name `<organization-login>.github.io` (replace the placeholder with your actual organization login, lowercase).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages → Build and deployment**. Under **Source** choose `Deploy from a branch`, and choose `main` and `/(root)`. Click **Save**.
4. Visit `https://<organization-login>.github.io/` once deployment finishes.

Before publishing, replace the placeholder GitHub link in `index.html` (`href="https://github.com/"`) with your organization's real profile URL, and remove the adjacent placeholder note.

The `.github/profile/README.md` repository is separate and controls the **GitHub organization profile**, not this website.

No build system or external CSS/JS libraries are needed.
